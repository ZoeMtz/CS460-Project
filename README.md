# Truck Failure Prediction Using Machine Learning (CS460 Final Project)

## Overview
This project uses machine learning models to predict truck failures using sensor data from the APS Failure Dataset.

##  Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

The best-performing model was XGBoost based on F1-score.
